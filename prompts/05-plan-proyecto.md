# Prompt 05, Plan de proyecto

**Cuándo usarlo:** al arrancar cualquier proyecto nuevo, sea de trabajo, personal o de negocio.

---

## Prompt

```
Quiero estructurar un proyecto nuevo.

Contexto:
- Nombre del proyecto: {{NOMBRE}}
- Qué es: {{DESCRIBA EN 2 O 3 FRASES QUÉ HACE ESTE PROYECTO Y POR QUÉ EXISTE}}
- Resultado esperado: {{QUÉ DEFINE EL ÉXITO; SEA ESPECÍFICO}}
- Plazo: {{FECHA OBJETIVO O "sin plazo definido"}}
- Recursos disponibles: {{TIEMPO POR SEMANA / PRESUPUESTO / PERSONAS}}
- Principales riesgos que ya identifico: {{SI LOS HAY}}
- Dependencias externas: {{QUÉ DEPENDE DE TERCEROS O DE OTRAS TAREAS}}

Con base en eso:
1. Crea la carpeta del proyecto en 03 Projects/{{NOMBRE}}/
2. Crea un README.md con: panorama, objetivo, resultado esperado, estado inicial
3. Parte el proyecto en fases o hitos principales
4. Para cada fase, lista las 3 a 5 tareas más importantes
5. Identifica qué puede trabar el proyecto y sugiere cómo mitigarlo
6. Define el primer paso que puedo dar hoy o mañana

Deja todo en el README.md que creaste.
```

---

## Qué esperar

Una carpeta de proyecto estructurada, con README completo, fases definidas, tareas por fase y un primer paso claro. Una estructura que crece a medida que el proyecto avanza.
