# Resources — Reglas de esta carpeta

Biblioteca personal reutilizable. Prompts, marcos de trabajo, referencias, plantillas.

## Qué va acá
- Prompts reutilizables (además de los que ya están en `prompts/`)
- Marcos de trabajo y metodologías de referencia
- Swipe files — ejemplos de contenido que funcionó
- Plantillas de documentos
- Archivos de proyectos terminados

## Organización sugerida
```
04 Resources/
├── prompts/       ← prompts adicionales, además de los del kit inicial
├── frameworks/    ← metodologías de referencia
├── swipe/         ← ejemplos e inspiración
├── plantillas/    ← modelos de documentos
└── archivo/       ← proyectos y contenidos terminados
```

## Reglas
- Cuando el usuario comparta un prompt, un marco de trabajo o una plantilla reutilizable: guárdalo acá con un nombre descriptivo
- Cuando el usuario diga "guarda esto para usarlo después": enrútalo para acá
- No crees subcarpetas vacías — crea la carpeta solo cuando haya contenido para ella
